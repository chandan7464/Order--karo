# 🍔 Order Karo

A full-stack food ordering web application built with the MERN stack.

## 🚀 Features
- User authentication (Login, Signup, Forgot Password)
- Browse restaurants/shops in your city
- Add items to cart and place orders
- Shop owner dashboard to manage orders
- Order history for both users and shop owners

## 🛠️ Tech Stack
- **Frontend:** React, Redux, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Auth:** JWT

## ⚙️ Installation

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm run dev
